# VERNIS — Premium Image Gallery

A responsive image gallery built for the CodeAlpha internship, styled as a private art-viewing room. Includes category filtering, a full-screen lightbox with keyboard/swipe navigation, and smooth hover animations.

## Features

- Responsive masonry-style grid layout (CSS Grid, `auto-flow: dense`)
- Lightbox view with next/previous navigation, keyboard shortcuts (←, →, Esc), and touch swipe support
- Category filters (Landscape, Portraiture, Architecture, Abstract, Still Life)
- Hover animations: image zoom, sliding caption plaque, animated corner frames
- Fully responsive: adapts from desktop down to mobile
- Respects `prefers-reduced-motion` for accessibility

## Tech Used

- HTML5
- CSS3 (Grid, custom properties, transitions)
- Vanilla JavaScript (no frameworks/libraries)

## How to Run Locally

1. Clone this repo
2. Open `index.html` in any browser

No build step or dependencies required.
